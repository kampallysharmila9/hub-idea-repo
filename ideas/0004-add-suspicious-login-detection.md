## Problem / Pain Point

Unauthorized users may attempt to access accounts using unusual login locations, repeated failed attempts, or unfamiliar devices.

## Proposed Solution

Detect suspicious login patterns and flag authentication attempts that exceed configurable security rules.

## Expected Benefit

Improve account security and help administrators identify potentially unauthorized access.
